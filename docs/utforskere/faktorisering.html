Faktorisering med produkt og sum

Å faktorisere x2+bx+cx^2 + bx + cx2+bx+c betyr å skrive det som et produkt (x+m)(x+n)(x + m)(x + n)(x+m)(x+n). Da må m⋅n=cm \cdot n = cm⋅n=c og m+n=bm + n = bm+n=b. Her ser du alle tallparene med riktig produkt, og brikkene blir et rektangel når du finner riktig par.

Matematikken bakHvorfor produkt og sum, og når det ikke går

Hvorfor produkt og sum?

Gang ut (x+m)(x+n)(x + m)(x + n)(x+m)(x+n):

(x+m)(x+n)=x2+nx+mx+mn=x2+(m+n)x+mn(x + m)(x + n) = x^2 + nx + mx + mn = x^2 + (m + n)x + mn(x+m)(x+n)=x2+nx+mx+mn=x2+(m+n)x+mn

Sammenlign med x2+bx+cx^2 + bx + cx2+bx+c. Da må m+n=bm + n = bm+n=b og m⋅n=cm \cdot n = cm⋅n=c. I rektangelet av brikker er mmm og nnn de to sidene i hjørnet med enerbrikker.

Fortegnene

  • Er c>0c > 0c>0, har tallene samme fortegn. Fortegnet er det samme som fortegnet til bbb.
  • Er c<0c < 0c<0, har tallene ulikt fortegn.

Når det ikke går med hele tall

Faktorene gir nullpunktene: (x+m)(x+n)=0(x + m)(x + n) = 0(x+m)(x+n)=0 når x=−mx = -mx=−m eller x=−nx = -nx=−n. Finnes det ingen hele tall som passer, kan nullpunktene være brøker eller røtter. Da kan vi bruke abc-formelen og skrive (x−x1)(x−x2)(x - x_1)(x - x_2)(x−x1​)(x−x2​). Er b2−4c<0b^2 - 4c < 0b2−4c<0, har uttrykket ingen nullpunkter og kan ikke faktoriseres i det hele tatt.

1To tall med produkt og sum

  1. Gjett

    Finn to tall med produkt 666 og sum 555. Skriv x2+5x+6x^2 + 5x + 6x2+5x+6 som et produkt.

  2. Test

    Vis x2+5x+6x^2 + 5x + 6x2+5x+6. Hvor mange tallpar har produkt 666? Hvilket har sum 555?

  3. Forklar

    Gang ut svaret ditt for å kontrollere. Forklar med rektangelet hvorfor produktet og summen må stemme.

Løsningsforslag

Tallparene med produkt 666 er 111 og 666, 222 og 333, −1-1−1 og −6-6−6, og −2-2−2 og −3-3−3. Bare 222 og 333 har sum 555. Altså er x2+5x+6=(x+2)(x+3)x^2 + 5x + 6 = (x + 2)(x + 3)x2+5x+6=(x+2)(x+3).

I rektangelet ligger 2+3=52 + 3 = 52+3=5 xxx-brikker langs kantene av x2x^2x2, og hjørnet har 2⋅3=62 \cdot 3 = 62⋅3=6 enerbrikker.

2Negativt konstantledd

  1. Gjett

    Faktoriser x2+x−6x^2 + x - 6x2+x−6. Hvilke fortegn må de to tallene ha når produktet er negativt?

  2. Test

    Vis x2+x−6x^2 + x - 6x2+x−6. Se på fortegnene i tabellen.

  3. Forklar

    Forklar hvorfor de to tallene må ha ulikt fortegn. Hvilke nullpunkter har uttrykket?

Løsningsforslag

Et negativt produkt krever ett positivt og ett negativt tall. Tallene 333 og −2-2−2 har produkt −6-6−6 og sum 111. Altså er x2+x−6=(x+3)(x−2)x^2 + x - 6 = (x + 3)(x - 2)x2+x−6=(x+3)(x−2).

Nullpunktene er x=−3x = -3x=−3 og x=2x = 2x=2. De har motsatt fortegn av tallene i parentesene.

3Negativ sum, positivt produkt

  1. Gjett

    Faktoriser x2−7x+12x^2 - 7x + 12x2−7x+12.

  2. Test

    Vis x2−7x+12x^2 - 7x + 12x2−7x+12. Finn alle tallparene med produkt 121212.

  3. Forklar

    Forklar hvorfor begge tallene må være negative. Hvordan ser du det på fortegnene til bbb og ccc?

Løsningsforslag

Produktet 121212 er positivt, så tallene har samme fortegn. Summen −7-7−7 er negativ, så begge er negative. Tallene −3-3−3 og −4-4−4 passer: x2−7x+12=(x−3)(x−4)x^2 - 7x + 12 = (x - 3)(x - 4)x2−7x+12=(x−3)(x−4).

4Når ingen tall passer

  1. Gjett

    Prøv å faktorisere x2+4x+5x^2 + 4x + 5x2+4x+5. Går det?

  2. Test

    Vis x2+4x+5x^2 + 4x + 5x2+4x+5. Hva står i tabellen? Hva er b2−4cb^2 - 4cb2−4c?

  3. Forklar

    Skriv uttrykket som (x+2)2+1(x + 2)^2 + 1(x+2)2+1. Bruk det til å forklare hvorfor uttrykket aldri blir 000, og derfor ikke kan faktoriseres.

Løsningsforslag

Tallparene med produkt 555 er 111 og 555, og −1-1−1 og −5-5−5. Summene er 666 og −6-6−6, ikke 444. Med hele tall går det ikke.

b2−4c=16−20=−4<0b^2 - 4c = 16 - 20 = -4 < 0b2−4c=16−20=−4<0. Uttrykket er (x+2)2+1(x + 2)^2 + 1(x+2)2+1, som alltid er minst 111. Det har ingen nullpunkter, og et produkt (x−x1)(x−x2)(x - x_1)(x - x_2)(x−x1​)(x−x2​) ville hatt nullpunkter. Derfor kan det ikke faktoriseres.

5Kvadratsetningene baklengs

  1. Gjett

    Faktoriser x2+6x+9x^2 + 6x + 9x2+6x+9 og x2−9x^2 - 9x2−9. Hva er spesielt med tallparene?

  2. Test

    Vis x2+6x+9x^2 + 6x + 9x2+6x+9 og x2−9x^2 - 9x2−9. Se på formen til rektangelet.

  3. Forklar

    Hvilke kvadratsetninger kjenner du igjen? Forklar hvordan du kan se det på uttrykket uten å lete i en tabell.

Løsningsforslag

x2+6x+9=(x+3)2x^2 + 6x + 9 = (x + 3)^2x2+6x+9=(x+3)2. Tallene er like, 333 og 333, og rektangelet blir et kvadrat. Det er første kvadratsetning: konstantleddet 999 er kvadratet av halvparten av 666.

x2−9=(x+3)(x−3)x^2 - 9 = (x + 3)(x - 3)x2−9=(x+3)(x−3). Tallene er like store med motsatt fortegn, så summen blir 000. Det er konjugatsetningen.
