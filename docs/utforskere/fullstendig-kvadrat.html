Fullstendig kvadrat

Uttrykket x2+bxx^2 + bxx2+bx er nesten et kvadrat. Bare ett hjørne mangler. Når du legger til hjørnet og trekker det fra igjen, kan du skrive x2+bx+cx^2 + bx + cx2+bx+c som (x+p)2+q(x + p)^2 + q(x+p)2+q. Den formen viser bunnpunktet og gjør likningen lett å løse.

Matematikken bakHvorfor metoden virker, og hva q forteller

Fra første kvadratsetning

Første kvadratsetning gir (x+p)2=x2+2px+p2(x + p)^2 = x^2 + 2px + p^2(x+p)2=x2+2px+p2. Tallet foran xxx er 2p2p2p. Skal det være bbb, må p=b2p = \frac{b}{2}p=2b​. Da har vi

x2+bx=(x+b2)2−(b2)2x^2 + bx = \left(x + \tfrac{b}{2}\right)^2 - \left(\tfrac{b}{2}\right)^2x2+bx=(x+2b​)2−(2b​)2

I figuren er x2+bxx^2 + bxx2+bx et kvadrat x2x^2x2 med to striper på b2⋅x\frac{b}{2} \cdot x2b​⋅x. Hjørnet (b2)2\left(\frac{b}{2}\right)^2(2b​)2 mangler. Vi legger det til for å få et helt kvadrat, og trekker det fra igjen så verdien ikke endres.

Hva formen forteller

Når x2+bx+c=(x+p)2+qx^2 + bx + c = (x + p)^2 + qx2+bx+c=(x+p)2+q:

  • Kvadratet (x+p)2(x + p)^2(x+p)2 er aldri negativt, og er 000 når x=−px = -px=−p. Derfor er den minste verdien qqq. Grafen har bunnpunkt i (−p,q)(-p, q)(−p,q).
  • Likningen x2+bx+c=0x^2 + bx + c = 0x2+bx+c=0 blir (x+p)2=−q(x + p)^2 = -q(x+p)2=−q. Er −q>0-q > 0−q>0, finnes to løsninger, x=−p±−qx = -p \pm \sqrt{-q}x=−p±−q​. Er −q<0-q < 0−q<0, finnes ingen.

abc-formelen kommer fra å gjøre akkurat dette med bokstaver i stedet for tall.

Hver oppgave har tre steg. Gjett først, uten å bruke utforskeren. Test så i utforskeren. Forklar til slutt med egne ord hvorfor det blir slik.

1Hjørnet som mangler

  1. Gjett

    Hva må du legge til x2+6xx^2 + 6xx2+6x for å få et fullstendig kvadrat?

  2. Test

    Vis x2+6xx^2 + 6xx2+6x uten hjørnet. Hvor brede er stripene? Slå på «Fyll inn hjørnet».

  3. Forklar

    Forklar hvorfor hjørnet er kvadratet av halvparten av 666, og ikke 666 eller 626^262.

Løsningsforslag

6x6x6x deles i to striper på 3x3x3x, én på hver side av x2x^2x2. Hjørnet mellom dem er et kvadrat med side 333. Det har areal 32=93^2 = 932=9.

Altså er x2+6x+9=(x+3)2x^2 + 6x + 9 = (x + 3)^2x2+6x+9=(x+3)2. Hjørnet er (62)2\left(\frac{6}{2}\right)^2(26​)2, fordi stripene er halvparten så brede som 666.

2Legg til og trekk fra

  1. Gjett

    Skriv x2+6x+5x^2 + 6x + 5x2+6x+5 på formen (x+p)2+q(x + p)^2 + q(x+p)2+q.

  2. Test

    Vis x2+6x+5x^2 + 6x + 5x2+6x+5. Les av ppp og qqq.

  3. Forklar

    Forklar hvorfor vi må trekke fra 999 etter at vi har lagt det til. Hva er bunnpunktet til grafen?

Løsningsforslag
x2+6x+5=(x2+6x+9)−9+5=(x+3)2−4x^2 + 6x + 5 = (x^2 + 6x + 9) - 9 + 5 = (x + 3)^2 - 4x2+6x+5=(x2+6x+9)−9+5=(x+3)2−4

Å legge til 999 endrer verdien. Når vi trekker fra 999 igjen, er uttrykket like stort som før. Bunnpunktet er (−3,−4)(-3, -4)(−3,−4), fordi (x+3)2(x + 3)^2(x+3)2 er minst når x=−3x = -3x=−3.

3Når bbb er negativ

  1. Gjett

    Skriv x2−4x+1x^2 - 4x + 1x2−4x+1 på formen (x+p)2+q(x + p)^2 + q(x+p)2+q. Er ppp positiv eller negativ?

  2. Test

    Vis x2−4x+1x^2 - 4x + 1x2−4x+1. Hvorfor blir hjørnet lagt til, selv om stripene tas bort?

  3. Forklar

    Kontroller svaret ved å sette x=0x = 0x=0 i begge formene.

Løsningsforslag

Halvparten av −4-4−4 er −2-2−2, og (−2)2=4(-2)^2 = 4(−2)2=4:

x2−4x+1=(x−2)2−4+1=(x−2)2−3x^2 - 4x + 1 = (x - 2)^2 - 4 + 1 = (x - 2)^2 - 3x2−4x+1=(x−2)2−4+1=(x−2)2−3

p=−2p = -2p=−2 er negativ. I figuren tar vi bort to striper på 2x2x2x. De overlapper i hjørnet, så hjørnet 444 tas bort to ganger. Det må legges til én gang. Det er andre kvadratsetning.

Kontroll med x=0x = 0x=0: 0−0+1=10 - 0 + 1 = 10−0+1=1 og (0−2)2−3=4−3=1(0 - 2)^2 - 3 = 4 - 3 = 1(0−2)2−3=4−3=1.

4Oddetall gir brøk

  1. Gjett

    Hva er halvparten av 555 i kvadrat? Prøv å skrive x2+5x+4x^2 + 5x + 4x2+5x+4 på formen (x+p)2+q(x + p)^2 + q(x+p)2+q.

  2. Test

    Vis x2+5x+4x^2 + 5x + 4x2+5x+4. Sammenlign med svaret ditt.

  3. Forklar

    Vis utregningen med brøker. Hvorfor er det lurt å skrive 444 som 164\frac{16}{4}416​?

Løsningsforslag

Halvparten av 555 er 52\frac{5}{2}25​, og (52)2=254\left(\frac{5}{2}\right)^2 = \frac{25}{4}(25​)2=425​.

x2+5x+4=(x+52)2−254+164=(x+52)2−94x^2 + 5x + 4 = \left(x + \frac{5}{2}\right)^2 - \frac{25}{4} + \frac{16}{4} = \left(x + \frac{5}{2}\right)^2 - \frac{9}{4}x2+5x+4=(x+25​)2−425​+416​=(x+25​)2−49​

Med felles nevner 444 blir det lett å trekke sammen −254+4-\frac{25}{4} + 4−425​+4.

5Løs likningen

  1. Gjett

    Bruk svaret i oppgave 2 til å løse x2+6x+5=0x^2 + 6x + 5 = 0x2+6x+5=0. Hva skjer med x2+2x+5=0x^2 + 2x + 5 = 0x2+2x+5=0?

  2. Test

    Vis x2+6x+5x^2 + 6x + 5x2+6x+5 og x2+2x+5x^2 + 2x + 5x2+2x+5. Se på løsningene i tabellen.

  3. Forklar

    Forklar hvordan du kan se på qqq om likningen har løsninger.

Løsningsforslag

(x+3)2−4=0(x + 3)^2 - 4 = 0(x+3)2−4=0 gir (x+3)2=4(x + 3)^2 = 4(x+3)2=4, så x+3=±2x + 3 = \pm 2x+3=±2. Løsningene er x=−1x = -1x=−1 og x=−5x = -5x=−5.

x2+2x+5=(x+1)2+4x^2 + 2x + 5 = (x + 1)^2 + 4x2+2x+5=(x+1)2+4. Likningen blir (x+1)2=−4(x + 1)^2 = -4(x+1)2=−4. Et kvadrat kan ikke være negativt, så likningen har ingen løsning.

Er q<0q < 0q<0, finnes to løsninger. Er q=0q = 0q=0, finnes én. Er q>0q > 0q>0, finnes ingen.
