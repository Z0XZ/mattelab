Alltid, noen ganger eller aldri sant?

Hvert spørsmål er en påstand. Elevene skal avgjøre om den er sann for alle verdier, for noen verdier eller for ingen verdier. Et moteksempel er nok til å vise at en påstand ikke alltid er sann.

Slik kan du bruke oppgavene: Elevene stemmer med fingrene: én finger for alltid, to for noen ganger og tre for aldri. La noen som er uenige, argumentere. Svaret «noen ganger» er ikke ferdig før eleven kan si når.

Du kan også bruke piltastene.
  1. Alltid, noen ganger eller aldri sant? 2x>x2x > x2x>x
    Vis forslag

    Noen ganger. Sant når x>0x > 0x>0. Med x=−3x = -3x=−3 blir det −6>−3-6 > -3−6>−3, som er usant. Med x=0x = 0x=0 blir det 0>00 > 00>0, som også er usant.

  2. Alltid, noen ganger eller aldri sant? (a+b)2=a2+b2(a + b)^2 = a^2 + b^2(a+b)2=a2+b2
    Vis forslag

    Noen ganger. Venstre side er a2+2ab+b2a^2 + 2ab + b^2a2+2ab+b2. Sidene er like bare når 2ab=02ab = 02ab=0, altså når a=0a = 0a=0 eller b=0b = 0b=0. Moteksempel: a=b=1a = b = 1a=b=1 gir 4=24 = 24=2.

  3. Alltid, noen ganger eller aldri sant? 3(x+2)=3x+23(x + 2) = 3x + 23(x+2)=3x+2
    Vis forslag

    Aldri. Venstre side er 3x+63x + 63x+6. Den er alltid 444 større enn 3x+23x + 23x+2. Feilen er å gange bare det første leddet i parentesen med 333.

  4. Alltid, noen ganger eller aldri sant? x2≥0x^2 \geq 0x2≥0
    Vis forslag

    Alltid. Et positivt tall ganger seg selv er positivt. Et negativt tall ganger seg selv er også positivt. Og 02=00^2 = 002=0.

  5. Alltid, noen ganger eller aldri sant? −x-x−x er et negativt tall.
    Vis forslag

    Noen ganger. −x-x−x betyr «det motsatte tallet av xxx». Hvis x=−5x = -5x=−5, er −x=5-x = 5−x=5, som er positivt. Påstanden er sann bare når x>0x > 0x>0.

  6. Alltid, noen ganger eller aldri sant? 1x<x\frac{1}{x} < xx1​<x
    Vis forslag

    Noen ganger. Sant for x=2x = 2x=2, fordi 12<2\frac{1}{2} < 221​<2. Usant for x=12x = \frac{1}{2}x=21​, fordi 2>122 > \frac{1}{2}2>21​. Påstanden er sann når x>1x > 1x>1 og når −1<x<0-1 < x < 0−1<x<0. For x=0x = 0x=0 er 1x\frac{1}{x}x1​ ikke definert.

  7. Alltid, noen ganger eller aldri sant? a+ba=b\frac{a + b}{a} = baa+b​=b
    Vis forslag

    Noen ganger. Med a=1a = 1a=1 og b=3b = 3b=3 får vi 4=34 = 34=3, som er usant. Men med a=2a = 2a=2 og b=2b = 2b=2 får vi 42=2\frac{4}{2} = 224​=2, som er sant.

    Det er ikke lov å «stryke» aaa. Riktig er a+ba=1+ba\frac{a + b}{a} = 1 + \frac{b}{a}aa+b​=1+ab​.

  8. Alltid, noen ganger eller aldri sant? x2=x\sqrt{x^2} = xx2​=x
    Vis forslag

    Noen ganger. Sant når x≥0x \geq 0x≥0. Med x=−3x = -3x=−3 blir venstre side 9=3\sqrt{9} = 39​=3, ikke −3-3−3.

    Vis forslag

  10. Alltid, noen ganger eller aldri sant? xx=1\frac{x}{x} = 1xx​=1
