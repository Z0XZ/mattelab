Hvilken passer ikke inn? Brøk

Hvert spørsmål viser fire tall eller uttrykk. Elevene skal velge ett som ikke passer inn, og begrunne valget. Ofte kan alle fire forsvares. Det er begrunnelsen som er poenget.

Slik kan du bruke oppgavene: Vis ett spørsmål. Elevene tenker alene i ett minutt og forklarer så for sidemannen. Samle inn begrunnelser i klassen før du åpner forslaget. Spør gjerne: «Hvem valgte en annen? Hvorfor?»

Du kan også bruke piltastene.

    • A24\dfrac{2}{4}42​
    • B35\dfrac{3}{5}53​
    • C610\dfrac{6}{10}106​
    • D0,60{,}60,6
    Vis forslag

    • B: Den eneste brøken som ikke kan forkortes.
    • C: Den eneste med nevner 101010, altså tideler.
    • D: Den eneste som er skrevet som desimaltall.

  3. Hvilken passer ikke inn?
    • A34+14\dfrac{3}{4} + \dfrac{1}{4}43​+41​
    • B12⋅2\dfrac{1}{2} \cdot 221​⋅2
    • C54−14\dfrac{5}{4} - \dfrac{1}{4}45​−41​
    • D12:14\dfrac{1}{2} : \dfrac{1}{4}21​:41​
    Vis forslag
    • D: Den eneste som ikke blir 111. 12:14=2\frac{1}{2} : \frac{1}{4} = 221​:41​=2, fordi 14\frac{1}{4}41​ går to ganger opp i 12\frac{1}{2}21​.

    • A: Den eneste addisjonen. C: Den eneste med en brøk større enn 111.
