Rasjonale funksjoner og polynomdivisjon

135 minutter1T

Første del handler om rasjonale funksjoner: hvor de er definert, og hva som skjer nær asymptotene. Andre del handler om polynomdivisjon. Til slutt kobles delene sammen: Går divisjonen opp, får grafen et hull. Går den ikke opp, får grafen en asymptote.

Mål for økta

  • Jeg kan finne definisjonsmengden og asymptotene til en rasjonal funksjon.
  • Jeg kan utføre polynomdivisjon og bruke resten til å avgjøre om x−rx - rx−r er en faktor.
  • Jeg kan forklare forskjellen på et hull og en asymptote.

Kompetansemål

  • 1T, mål 9 «utforske og beskrive egenskapene ved polynomfunksjoner, rasjonale funksjoner, eksponentialfunksjoner og potensfunksjoner»
  • 1T, mål 11 «forklare polynomdivisjon og bruke det til å omskrive algebraiske uttrykk, drøfte funksjoner og løse ligninger og ulikheter»

1Asymptoter

  1. a

    Finn definisjonsmengden til f(x)=2x−1x+3f(x) = \frac{2x - 1}{x + 3}f(x)=x+32x−1​.

  2. b

    Finn asymptotene.

  3. c

    Finn nullpunktet og skjæringen med y-aksen.

Løsningsforslag

a) Nevneren er null når x=−3x = -3x=−3. Definisjonsmengden er alle xxx unntatt −3-3−3.

b) Loddrett asymptote x=−3x = -3x=−3, fordi telleren ikke er null der. Vannrett asymptote y=2y = 2y=2, fordi brøken nærmer seg 2xx=2\frac{2x}{x} = 2x2x​=2 for store xxx.

c) Nullpunkt: 2x−1=02x - 1 = 02x−1=0 gir x=12x = \frac{1}{2}x=21​. Skjæring med y-aksen: f(0)=−13f(0) = -\frac{1}{3}f(0)=−31​.

2Faktoriser med polynomdivisjon

  1. a

    Vis at x=2x = 2x=2 er et nullpunkt for P(x)=x3+2x2−5x−6P(x) = x^3 + 2x^2 - 5x - 6P(x)=x3+2x2−5x−6.

  2. b

    Utfør P(x):(x−2)P(x) : (x - 2)P(x):(x−2), og faktoriser P(x)P(x)P(x) helt.

Løsningsforslag

a) P(2)=8+8−10−6=0P(2) = 8 + 8 - 10 - 6 = 0P(2)=8+8−10−6=0.

b) Polynomdivisjonen gir

(x3+2x2−5x−6):(x−2)=x2+4x+3(x^3 + 2x^2 - 5x - 6) : (x - 2) = x^2 + 4x + 3(x3+2x2−5x−6):(x−2)=x2+4x+3

og x2+4x+3=(x+1)(x+3)x^2 + 4x + 3 = (x + 1)(x + 3)x2+4x+3=(x+1)(x+3). Altså er P(x)=(x−2)(x+1)(x+3)P(x) = (x - 2)(x + 1)(x + 3)P(x)=(x−2)(x+1)(x+3).

3Hull eller asymptote?

  1. a

    Forenkle g(x)=x2−4x−2g(x) = \frac{x^2 - 4}{x - 2}g(x)=x−2x2−4​. Hva skjer med grafen i x=2x = 2x=2?

Løsningsforslag

x2−4=(x−2)(x+2)x^2 - 4 = (x - 2)(x + 2)x2−4=(x−2)(x+2), så g(x)=x+2g(x) = x + 2g(x)=x+2 når x≠2x \neq 2x=2. Grafen er linja y=x+2y = x + 2y=x+2 med et hull i (2,4)(2, 4)(2,4). Det er ingen asymptote, fordi divisjonen går opp.

4Skrå asymptote

  1. a

    Utfør polynomdivisjonen (x2+3x):(x−1)(x^2 + 3x) : (x - 1)(x2+3x):(x−1).

  2. b

    Finn asymptotene til h(x)=x2+3xx−1h(x) = \frac{x^2 + 3x}{x - 1}h(x)=x−1x2+3x​.

Løsningsforslag

a) (x2+3x):(x−1)=x+4(x^2 + 3x) : (x - 1) = x + 4(x2+3x):(x−1)=x+4 med rest 444. Altså er h(x)=x+4+4x−1h(x) = x + 4 + \frac{4}{x - 1}h(x)=x+4+x−14​.

b) Loddrett asymptote x=1x = 1x=1. Skrå asymptote y=x+4y = x + 4y=x+4, fordi 4x−1\frac{4}{x - 1}x−14​ går mot 000 når xxx blir stor.
