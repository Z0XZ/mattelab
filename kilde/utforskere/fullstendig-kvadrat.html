--- tittel: Fullstendig kvadrat beskrivelse: Se hvorfor x² + bx mangler et hjørne for å bli et kvadrat. Skriv x² + bx + c som (x + p)² + q, finn bunnpunktet og løs likningen. type: utforsker fag: 1T tema: algebra, likninger ikon: fullstendig-kvadrat skript: utforskere/fullstendig.js ---

Uttrykket $x^2 + bx$ er nesten et kvadrat. Bare ett hjørne mangler. Når du legger til hjørnet og trekker det fra igjen, kan du skrive $x^2 + bx + c$ som $(x + p)^2 + q$. Den formen viser bunnpunktet og gjør likningen lett å løse.

Matematikken bakHvorfor metoden virker, og hva q forteller

Fra første kvadratsetning

Første kvadratsetning gir $(x + p)^2 = x^2 + 2px + p^2$. Tallet foran $x$ er $2p$. Skal det være $b$, må $p = \frac{b}{2}$. Da har vi

$$x^2 + bx = \left(x + \tfrac{b}{2}\right)^2 - \left(\tfrac{b}{2}\right)^2$$

I figuren er $x^2 + bx$ et kvadrat $x^2$ med to striper på $\frac{b}{2} \cdot x$. Hjørnet $\left(\frac{b}{2}\right)^2$ mangler. Vi legger det til for å få et helt kvadrat, og trekker det fra igjen så verdien ikke endres.

Hva formen forteller

Når $x^2 + bx + c = (x + p)^2 + q$:

  • Kvadratet $(x + p)^2$ er aldri negativt, og er $0$ når $x = -p$. Derfor er den minste verdien $q$. Grafen har bunnpunkt i $(-p, q)$.
  • Likningen $x^2 + bx + c = 0$ blir $(x + p)^2 = -q$. Er $-q > 0$, finnes to løsninger, $x = -p \pm \sqrt{-q}$. Er $-q < 0$, finnes ingen.

abc-formelen kommer fra å gjøre akkurat dette med bokstaver i stedet for tall.

Oppgaver

{{elevark}}

Hver oppgave har tre steg. Gjett først, uten å bruke utforskeren. Test så i utforskeren. Forklar til slutt med egne ord hvorfor det blir slik.

1Hjørnet som mangler

  1. Gjett

    Hva må du legge til $x^2 + 6x$ for å få et fullstendig kvadrat?

  2. Test

    Vis $x^2 + 6x$ uten hjørnet. Hvor brede er stripene? Slå på «Fyll inn hjørnet».

  3. Forklar

    Forklar hvorfor hjørnet er kvadratet av halvparten av $6$, og ikke $6$ eller $6^2$.

Løsningsforslag

$6x$ deles i to striper på $3x$, én på hver side av $x^2$. Hjørnet mellom dem er et kvadrat med side $3$. Det har areal $3^2 = 9$.

Altså er $x^2 + 6x + 9 = (x + 3)^2$. Hjørnet er $\left(\frac{6}{2}\right)^2$, fordi stripene er halvparten så brede som $6$.

2Legg til og trekk fra

  1. Gjett

    Skriv $x^2 + 6x + 5$ på formen $(x + p)^2 + q$.

  2. Test

    Vis $x^2 + 6x + 5$. Les av $p$ og $q$.

  3. Forklar

    Forklar hvorfor vi må trekke fra $9$ etter at vi har lagt det til. Hva er bunnpunktet til grafen?

Løsningsforslag
$$x^2 + 6x + 5 = (x^2 + 6x + 9) - 9 + 5 = (x + 3)^2 - 4$$

Å legge til $9$ endrer verdien. Når vi trekker fra $9$ igjen, er uttrykket like stort som før. Bunnpunktet er $(-3, -4)$, fordi $(x + 3)^2$ er minst når $x = -3$.

3Når $b$ er negativ

  1. Gjett

    Skriv $x^2 - 4x + 1$ på formen $(x + p)^2 + q$. Er $p$ positiv eller negativ?

  2. Test

    Vis $x^2 - 4x + 1$. Hvorfor blir hjørnet lagt til, selv om stripene tas bort?

  3. Forklar

    Kontroller svaret ved å sette $x = 0$ i begge formene.

Løsningsforslag

Halvparten av $-4$ er $-2$, og $(-2)^2 = 4$:

$$x^2 - 4x + 1 = (x - 2)^2 - 4 + 1 = (x - 2)^2 - 3$$

$p = -2$ er negativ. I figuren tar vi bort to striper på $2x$. De overlapper i hjørnet, så hjørnet $4$ tas bort to ganger. Det må legges til én gang. Det er andre kvadratsetning.

Kontroll med $x = 0$: $0 - 0 + 1 = 1$ og $(0 - 2)^2 - 3 = 4 - 3 = 1$.

4Oddetall gir brøk

  1. Gjett

    Hva er halvparten av $5$ i kvadrat? Prøv å skrive $x^2 + 5x + 4$ på formen $(x + p)^2 + q$.

  2. Test

    Vis $x^2 + 5x + 4$. Sammenlign med svaret ditt.

  3. Forklar

    Vis utregningen med brøker. Hvorfor er det lurt å skrive $4$ som $\frac{16}{4}$?

Løsningsforslag

Halvparten av $5$ er $\frac{5}{2}$, og $\left(\frac{5}{2}\right)^2 = \frac{25}{4}$.

$$x^2 + 5x + 4 = \left(x + \frac{5}{2}\right)^2 - \frac{25}{4} + \frac{16}{4} = \left(x + \frac{5}{2}\right)^2 - \frac{9}{4}$$

Med felles nevner $4$ blir det lett å trekke sammen $-\frac{25}{4} + 4$.

5Løs likningen

  1. Gjett

    Bruk svaret i oppgave 2 til å løse $x^2 + 6x + 5 = 0$. Hva skjer med $x^2 + 2x + 5 = 0$?

  2. Test

    Vis $x^2 + 6x + 5$ og $x^2 + 2x + 5$. Se på løsningene i tabellen.

  3. Forklar

    Forklar hvordan du kan se på $q$ om likningen har løsninger.

Løsningsforslag

$(x + 3)^2 - 4 = 0$ gir $(x + 3)^2 = 4$, så $x + 3 = \pm 2$. Løsningene er $x = -1$ og $x = -5$.

$x^2 + 2x + 5 = (x + 1)^2 + 4$. Likningen blir $(x + 1)^2 = -4$. Et kvadrat kan ikke være negativt, så likningen har ingen løsning.

Er $q < 0$, finnes to løsninger. Er $q = 0$, finnes én. Er $q > 0$, finnes ingen.
